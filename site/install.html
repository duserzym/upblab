UPb Lab / Install

Install and connect.

Choose a lab server, sign in once, and open the workflow.

Get the app

Download an installer from GitHub Releases: a .dmg for macOS (Apple Silicon), or a .msi or -setup.exe for Windows (x86-64). If no installer is published yet, build from source:

make setup
make build

See the developer guide for prerequisites. The build command prints the installer location.

macOS first launch

  1. Open the disk image and drag UPb Lab to Applications. Launch it from Applications once to register its app links.
  2. If an unsigned or not-notarized download is blocked, close the warning. Open System Settings > Privacy & Security, choose Open Anyway, and confirm.

Windows first launch

The NSIS -setup.exe installs for your user; the .msi needs administrator rights. For an unsigned installer, SmartScreen may show Windows protected your PC. Choose More info, then Run anyway. The installer also installs WebView2 if needed.

Choose Lab server

  1. On first run, choose Lab server.
  2. Enter the UPbDB server address supplied by the lab manager, then choose Continue.
  3. Open Sign in in the tab bar, then choose Sign in… in the dialog.
  4. The one button opens UPbDB’s sign-in page in your browser. Use ORCID or your lab account, then choose Sign UPb Lab in. Allow the browser to return to UPb Lab.

The sign-in is shared with the module tabs; launching UPbRPy Studio passes a one-time sign-in code. Use the account button to Sign out.

This computer runs a local UPbDB and PostgreSQL when a service bundle or a development checkout is available. Release builds offer Lab server only until the UPbDB service bundle is published. See the installation reference for local mode and file locations.

Outside the lab network

To reach the lab desktop server, install Tailscale and ask the lab manager to share the lab server with you. Connect Tailscale and use the address they give you in Lab server.

Updates

UPb Lab checks GitHub releases in the background. Open Settings > Updates and choose Check now. Automatic downloads are on by default. When a download is ready, choose Restart to update.

Stable receives published releases; Beta (pre-releases) also receives pre-releases. Bundled modules update with UPb Lab. UPbRPy Studio updates from its own Settings. Read the update reference for signing and release details.
