UPb Lab / FAQ

Troubleshoot the connection.

Start with the server address and sign-in, then check the app paths and update status.

Cannot reach the server

Check Settings > UPbDB > Lab server > Server URL against the address supplied by the lab manager. Test that address in your browser. Outside the lab network, connect Tailscale and confirm that the lab manager has shared the lab server with you.

In Sessions, use Retry now after reconnecting, or Change server URL to fix the address. If the browser cannot reach it either, ask the lab manager whether the server is running.

Sign-in does not return to the app

Open the installed app once from Applications on macOS so the system registers its links. Start sign-in from UPb Lab: Sign in, then Sign in…. Finish on UPbDB’s browser page, choose Sign UPb Lab in, and allow the browser to open the app.

The returning link must match the sign-in started by UPb Lab. If an old browser tab is left open, cancel the pending attempt in the app and start again. A desktop development window does not receive system callbacks the same way as the installed app; use a built app for that check.

An update check fails or finds nothing

Open Settings > Updates and choose Check now after checking your internet connection. A release must be published with update artifacts before the app can receive it. Stable excludes pre-releases; Beta includes them.

If the build cannot install updates, use Open download page when offered, or download an installer from Releases. A downloaded update is installed only when you choose Restart to update.

Where files live

In Lab server mode, UPbDB stores uploaded sessions and reduction results on the server. Opening a file in UPb Lab routes it to the appropriate module; it does not move the whole database onto your computer.

Local settings use the existing edu.umn.upbstudio app identifier. On macOS they are in ~/Library/Application Support/edu.umn.upbstudio/; on Windows they are in %APPDATA%\edu.umn.upbstudio\. Sign-in tokens are in the system keychain or Windows Credential Manager.

In This computer mode, the PostgreSQL directory and the UPbDB data root are separate. Back up both with the app closed. Do not delete local-service.json: it contains the generated password needed to reach the local database. The installation reference lists the full locations.

Why are results or images missing?

Review needs a complete reduction run submitted to UPbDB. A raw session alone has no reduced results. A depth profile must have been stored by that run. Image selection needs a linked spot and atlas; publish the atlas from GrainAtlas to its mount.
