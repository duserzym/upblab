UPb Lab / Settings

Configure the connection and display.

Settings holds the UPbDB connection, Studio path, appearance and update controls.

UPbDB

Choose Lab server, edit Server URL and choose Save. Use the address supplied by the lab manager. This computer needs a service bundle or development checkout; see local mode availability.

UPbRPy Studio

Leave Path empty to use the detected app, or enter the installed application’s path. UPbRPy checkout (development) launches a development copy. Choose Save after changing these fields.

Appearance and layout

System follows your operating system by default. Light and Dark override it for every app tab. Reset layout forgets the saved window size and position.

Updates and modules

In Updates, choose Check now, set Download updates automatically, or choose Stable or Beta (pre-releases). Use Restart to update when a download is ready.

In this build lists bundled modules, the UPbDB service, PostgreSQL and the detected UPbRPy Studio. Bundled modules update with UPb Lab; Studio has its own updater. UPb Standards > Check standards checks the reference material files separately.
