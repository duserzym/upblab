UPb Lab / Sessions

Store and inspect sessions.

The Sessions tab opens the web page of the lab database server, UPbDB.

Upload a laser session

  1. On Home, choose Upload LA-ICP-MS session and select the session export.
  2. The shell sends the files to UPbDB’s ingest dialog in Sessions. Confirm the ingest there.
  3. Return Home to find the stored session. Open it in Sessions or send it to UPbRPy Studio for reduction.

Accepted inputs include a Rich CSV, a per-spot export folder, a zip, or the Rich CSV and its per-spot folder together. The shell routes the input; UPbDB imports and stores it.

Reduce and review

Open the Reduce tab and choose Open in Studio for a session. A submitted reduction is stored in UPbDB, then becomes available in Review.

If the page cannot connect

Use Retry now to check the server again, or Change server URL to open Settings. Check the address and your network or Tailscale connection. See server troubleshooting.
