UPb Lab / Reduce

Open a session in Studio.

UPbRPy Studio performs the reduction. UPb Lab opens the session and shows its stored results afterwards.

Launch a session

  1. Install UPbRPy Studio on this computer.
  2. Sign in to UPbDB in UPb Lab, then open Reduce.
  3. Choose Open in Studio for a session. UPb Lab launches Studio with a one-time sign-in code, valid for five minutes.
  4. Reduce and submit from Studio. Use Review once a completed run is stored.

If Studio is not found

Choose Studio settings. In Settings > UPbRPy Studio > Path, select the installed .app on macOS or .exe on Windows. Developers can set UPbRPy checkout (development).

Studio opens as a separate application. In the web shell, follow Open in Studio using the app link registered by Studio’s installer.

Return to a stored run

Review’s Edit in UPbRPy Studio opens the session or run for the chosen spot. UPb Lab does no data reduction and does not change the stored values through its plot controls.
