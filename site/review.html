UPb Lab / Review

Read results beside their images.

Review connects stored results, spot metadata and the published SEM atlas. Changes belong in the editing apps.

Choose a scope

Choose a session or mount and a reduction run in the scope bar. A mount uses each session’s preferred run. The spot list also includes spots that have not been measured.

Sample chips control visibility. Click to toggle a sample, Shift-click to toggle a range, or Alt/Option-click to show only that sample. All, None, Samples and Standards control groups.

Concordia

Choose Concordia for Wetherill or Tera-Wasserburg plots. Ellipses use stored results, their 2σ uncertainties and error correlations; reference curves are drawn for display. Selecting a point selects its spot and updates the details.

Geochemistry board

Choose Geochemistry to compare result columns in multiple panels. Axis pickers, log scales and Presets configure the display. Mineral presets include zircon, apatite, rutile, titanite and monazite. Add up to 12 panels and maximise a panel for a closer look.

Stored columns take precedence. Display arithmetic on stored concentrations includes CI normalisation, quotients, Eu/Eu*, Ce/Ce* and the sum of REE + Y. Derived axes say from stored ppm and carry no uncertainty. Dates, thermometers and their uncertainties are read only when stored.

Depth profile

Select a visible spot and choose Depth profile. The plot reads the profile saved by its reduction run, including stored channels and uncertainty bands where available. It does not calculate ratios or dates from raw sweeps.

SEM images beside the plots

Enable SEM images in the scope bar to show the published atlas beside Review. The panel uses the bundled GrainAtlas build in a read-only viewer presentation. A plot selection focuses the corresponding image spot; selecting a linked spot in the SEM images panel selects its result. See SEM images in Review for the maximised panel, mount map, Fit and area menu.

Move and resize the Spots, Age & plots, Spot metadata and SEM images panels. Use Balanced, Plots focus or Image focus to restore a preset. Panels can be maximised and restored; the layout choice is remembered.

See sample groups on the mount

With SEM images on and no single spot selected, the mount map inset outlines where each shown sample’s spots sit on the mount in that sample’s Review colour. The inset’s header counts the samples. This group view appears after opening a scope, toggling Group unregistered by spot name, or using sample chips, sample rows, All, Samples or Standards. Picking a single spot returns the inset to that spot.

Edit in the appropriate app

  • Edit in UPbRPy Studio opens the session or run in Studio with the selected acquisition when available. Reduction happens there, then results are submitted to UPbDB.
  • Edit in grainatlas opens the linked project in standalone GrainAtlas on desktop, or its hosted build in a new tab on the web. Publish image changes there to update the atlas.

These actions need a linked session, run or image project. An unmeasured spot has no reduction to edit. See Reduce if Studio is not found.
