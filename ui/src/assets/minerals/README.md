# Mineral icons

Copied unchanged from bracketeer (`src/assets/minerals/`, commit b532aa4,
MIT, same author), which generates them with `scripts/make_minerals.py` from
the representative crystals of Yiming Zhang's mineral-habit-matrix
(https://github.com/duserzym/mineral-habit-matrix, commit c744553). One light
and one dark SVG per mineral; "other" is quartz in neutral grey. Regenerate in
bracketeer and copy again rather than editing these files.
